## Known blockers / risks (non-blocking)
- Audit Phase B (measured, `.claude/docs/stages/audit-2026-10/phaseB/report.md`, 200 seeds/config): pure-noise datasets get a top-tier chart in 84 % (n = 30, 20 cols) / 30 % (n = 30, 5 cols), 0 % at n ≥ 100; evidence "strong" entries on noise at every n (interaction share not df-corrected → line `group_by` on ~100 % of noise datasets at n = 1000); two independent random walks → recommended scatter in 64–70 %; probes: `time_pattern` false pass 18.7 % at n = 30. BH at q = 0.05 per dataset removes 93–100 % of null flags. No multiplicity correction yet (needs a decision on D11 / tiers; changes rules-only output).
- Audit gate trade-off: the allowlist gate makes most real LLM wording fall back to the claim template; empty count/sum time buckets show as gaps, not zeros (backend fill = product decision); business-day lines break at holidays.
- Stage 20b limitations: there is no cat×cat association statistic in the evidence (no Cramér's V), so a composition rides on the cat1×cat2×num interaction share — which is about the **mean** of the measure, not literally about the mix of shares — and a flow rides on column naming alone. `_interactions` only scans the three categoricals with the highest `best_eta` (`TOP_CATS_FOR_INTERACTIONS` 3), so a real composition can be missed on a wide dataset. `_NON_ADDITIVE_NAME_RE` is a name heuristic (a summable column called `rate_card` is skipped; a rate named `v` is not). A sankey whose source and target happen to be copies renders as an empty chart (every pair is a self-loop) — the payload says so (`self_loops`, `n_points` 0) and the UI shows the empty state. `rose` remains an Explore / LLM choice by design.
- `TYPE_DECAY` (0.85) is not what drops `cnt across hr` on hour_like: measured in 19.2 on the 14 datasets, `TYPE_DECAY` 0.85 / 0.9 / 0.95 give byte-identical rules-only output, and 0.99 / 1.0 change only one exploratory slot on hour_like (`histogram cnt`, 0.50 → `line dteday×windspeed`, 0.516) — `cnt across hr` never comes back at any value.
